1. What is Python?

Python ek high-level, general-purpose, interpreted programming language hai. Python ko readability aur simple syntax ke liye jaana jaata hai.

Simple Definition:
Python ek programming language hai jiska use automation, web development, data analysis, AI/ML, scripting, DevOps aur bahut saare areas me kiya jaata hai.

Python ko simple kyun maana jaata hai?

  • Syntax relatively simple aur readable hai.
  • Code kam lines me likha ja sakta hai.
  • Large standard library available hai.
  • Bahut saare third-party packages available hain.
  • Linux, Windows aur macOS par run kar sakta hai.

Simple Example

print("Hello, World!")

Yahaan print() function screen par output display karta hai.

DevOps Connection: DevOps engineer ke liye Python ka main benefit automation aur scripting hai.

2. Python in DevOps

DevOps me repetitive manual tasks ko automate karna bahut important hota hai. Python se hum scripts bana kar repetitive tasks ko automate kar sakte hain.

DevOps me Python kahaan use hota hai?

Area Python ka Use
Automation Repetitive tasks automate karna
Cloud AWS, Azure, GCP resources ke saath automation
Linux Files, processes aur system tasks automate karna
CI/CD Build, test aur deployment related scripting
Monitoring Logs, metrics aur health checks automate karna
Docker Container-related automation aur API interaction
Kubernetes Kubernetes API aur automation tools ke saath kaam
APIs REST APIs ko call aur automate karna

Example: Disk Usage Check

import shutil

total, used, free = shutil.disk_usage("/")

print("Total:", total)
print("Used:", used)
print("Free:", free)

Is tarah Python se system information retrieve karke monitoring ya automation scripts banayi ja sakti hain.

Example: Command Execute Karna

import subprocess

result = subprocess.run(
    ["ls", "-la"],
    capture_output=True,
    text=True
)

print(result.stdout)
Important: DevOps me Python ka goal sirf Python Developer banna nahi hai. Tumhara focus Python ko automation + cloud + Linux + CI/CD + APIs ke liye use karna hona chahiye.

4. How to Execute Python & Interpreter

Python Interpreter kya hai?

Python interpreter ek program/software component hai jo Python code ko execute karta hai. Practical terms me, jab tum Python command chalate ho, Python runtime tumhare code ko process karke execute karta hai.

Check Python Version

python3 --version

Python Interactive Mode

python3

Ab tum directly commands run kar sakte ho:

>>> 10 + 20
30

>>> print("Hello Python")
Hello Python

Interactive mode se bahar aane ke liye:

exit()

Python File Create Karna

Example file: hello.py

print("Hello from Python")

Python File Run Karna

python3 hello.py

Linux me Shebang

#!/usr/bin/env python3

print("Hello DevOps")

File executable banane ke liye:

chmod +x hello.py

Run:

./hello.py
DevOps Tip: Linux automation scripts me #!/usr/bin/env python3 ka use common hai.

5. Variables & Data Types

Variable kya hai?

Variable ek name/reference hai jiske through hum kisi value ko program me use karte hain. 

name = "Pavan"
age = 22
salary = 40000

Yahaan:

  • name → variable
  • "Pavan" → string value
  • age → variable
  • 22 → integer value

Important Built-in Data Types

Data Type Example Meaning
int 10 Whole number
float 10.5 Decimal number
str "Python" Text
bool True Boolean value
list [1, 2, 3] Ordered, mutable collection
tuple (1, 2, 3) Ordered, immutable collection
dict {"name": "Pavan"} Key-value collection
set {1, 2, 3} Unique elements collection

Example

name = "Pavan"
age = 22
height = 5.8
is_student = True

print(name)
print(age)
print(height)
print(is_student)

6. type() Function

type() function kisi value ya variable ka data type batata hai. 

x = 10
name = "Pavan"
price = 99.50
status = True

print(type(x))
print(type(name))
print(type(price))
print(type(status))

Output:

<class 'int'>
<class 'str'>
<class 'float'>
<class 'bool'>
Debugging Tip: Jab input ya API response ka data type samajh nahi aa raha ho, type() bahut useful hota hai.

7. Type Conversion

Type conversion ka matlab ek data type ki value ko doosre compatible data type me convert karna.

Common Conversion Functions

Function Example
int() int("10")
float() float("10.5")
str() str(100)
bool() bool(1)

Example

age = "22"

age = int(age)

print(age)
print(type(age))

Important: Invalid Conversion

number = int("hello")

Ye ValueError dega kyunki "hello" ko integer me convert nahi kiya ja sakta.

8. input() Function

input() user se keyboard ke through data lene ke liye use hota hai. 

name = input("Enter your name: ")

print("Hello", name)

Important Point

input() normally user input ko string ke form me return karta hai. 

age = input("Enter age: ")

print(type(age))

Age ko number ke form me use karna ho to:

age = int(input("Enter age: "))

print(age + 1)

DevOps Example

server = input("Enter server name: ")
port = int(input("Enter port: "))

print("Server:", server)
print("Port:", port)

11. Comparison Operators

Comparison operators do values ko compare karte hain aur result generally True ya False hota hai.

Operator Meaning Example Result
== Equal 10 == 10 True
!= Not Equal 10 != 5 True
> Greater Than 10 > 5 True
< Less Than 10 < 5 False
>= Greater or Equal 10 >= 10 True
<= Less or Equal 10 <= 5 False

Example

cpu_usage = 75

print(cpu_usage > 80)
print(cpu_usage == 75)
print(cpu_usage != 50)

DevOps Use Case

cpu_usage = 85

if cpu_usage > 80:
    print("Warning: High CPU usage")

Ye monitoring automation ka basic concept demonstrate karta hai: metric ko threshold se compare karo aur required action lo.

12. f-Strings

f-string Python me strings ke andar variables aur expressions ko easily insert karne ka convenient method hai.

Basic Syntax

name = "Pavan"
print(f"Hello {name}")

Multiple Variables

name = "Pavan"
role = "DevOps Engineer"

print(f"My name is {name} and I am learning {role}.")

Expression inside f-string

a = 10
b = 20

print(f"Sum = {a + b}")

Formatting Numbers

price = 99.5678

print(f"Price: {price:.2f}")

Output:

Price: 99.57

DevOps Example

server = "web-server-01"
cpu = 87

print(f"Server {server} CPU usage is {cpu}%")
Why f-string? Logs, status messages, monitoring output aur automation scripts me readable messages generate karne ke liye bahut useful hai.
