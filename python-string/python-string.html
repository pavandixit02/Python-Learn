1. What is String?

Python me String characters ka sequence hota hai. String ka use text/data ko store karne ke liye hota hai.

Simple Definition:
String = Text data ka collection/sequence.

Examples

name = "Pavan"
city = "Mathura"
message = "Hello Python"
server = "web-server-01"

In sabhi variables me string values store hain.

Empty String

name = ""

"" ek valid empty string hai. Isme koi character nahi hai, lekin data type str hi hoga. 

name = ""

print(type(name))
print(len(name))
DevOps Example: Server names, file names, URLs, IP addresses, log messages, usernames, environment names aur command output me strings bahut commonly use hote hain.

2. Single & Double Quotes

Python me string create karne ke liye commonly single quotes ' ' aur double quotes " " dono use kar sakte hain.

Single Quotes

name = 'Pavan'
print(name)

Double Quotes

name = "Pavan"
print(name)

Dono ka result string hi hota hai:

print(type('Pavan'))
print(type("Pavan"))

Quotes ke andar Quotes

Agar string ke andar apostrophe ho to outer quotes carefully choose kar sakte ho. 

message = "Pavan's Python class"
print(message)

Ya escaping ka use:

message = 'Pavan\'s Python class'
print(message)
Common Mistake: Opening aur closing quote same type ka hona chahiye.

Wrong: name = "Pavan'

Triple Quotes

Multi-line strings ke liye triple single ya triple double quotes use kiye ja sakte hain. 

message = """Hello Pavan
Welcome to Python
Learn Python for DevOps"""

print(message)

3. String Concatenation

Concatenation ka matlab hai do ya multiple strings ko combine karna. Python me commonly + operator ka use hota hai. 

first_name = "Pavan"
last_name = "Dixit"

full_name = first_name + " " + last_name

print(full_name)
Pavan Dixit

Without Space

a = "Hello"
b = "World"

print(a + b)
HelloWorld

With Space

print(a + " " + b)
Hello World

String + Number?

Directly string aur integer ko + se combine nahi kar sakte. 

age = 22

# Wrong:
# print("Age: " + age)

Number ko string me convert karo:

age = 22

print("Age: " + str(age))
Modern Python me readable output ke liye concatenation ke instead f-string bhi use karna useful hai: print(f"Age: {age}")

4. String Length — len()

len() function string me kitne characters hain ye count karta hai. 

name = "Pavan"

print(len(name))
5

Characters ka Count

text = "Python"

print(len(text))
6

Space bhi count hota hai

text = "Hello World"

print(len(text))
11

"Hello" = 5, space = 1, "World" = 5 → total 11.

Empty String

text = ""

print(len(text))
0
DevOps Use: Input validation, file names, environment variables aur configuration values ki length check karne me len() useful hai.

5. Indexing

String ek sequence hai, isliye hum uske individual characters ko index ke through access kar sakte hain.

Python me indexing 0 se start hoti hai. 
text = "Python"

# Index:   0 1 2 3 4 5
# Character P y t h o n

print(text[0])
print(text[1])
print(text[2])
print(text[5])
P y t n

Visual Representation

Character P y t h o n
Index 0 1 2 3 4 5

Last Character

text = "Python"

print(text[len(text) - 1])

Output:

n
Common Error: Agar index range se bahar chala gaya to IndexError milega.

Example: text = "Python"; print(text[10])

6. Negative Indexing

Python me negative indexing se string ko end se access kar sakte hain.

Character P y t h o n
Positive 0 1 2 3 4 5
Negative -6 -5 -4 -3 -2 -1 
text = "Python"

print(text[-1])
print(text[-2])
print(text[-3])
n o h
Easy Rule: -1 = last character, -2 = second-last, -3 = third-last.

Practical Example

filename = "server.log"

print(filename[-3:])
log

7. Slicing

Slicing ka use string ke ek portion/part ko extract karne ke liye hota hai.

Syntax: string[start:stop]
Start index included hota hai, stop index excluded hota hai. 
text = "Python"

print(text[0:2])
print(text[1:4])
print(text[2:6])
Py yth thon

Important Rule

text[1:4] ka matlab indexes 1, 2, 3 — index 4 include nahi hota.

Start Omit Karna

text = "Python"

print(text[:3])
Pyt

[:3] = beginning se index 3 se pehle tak.

Stop Omit Karna

print(text[2:])
thon

[2:] = index 2 se end tak.

Copy Entire String

print(text[:])
Python

8. Useful Slicing Techniques

1. Step

Slicing ka complete form hai: string[start:stop:step] 

text = "Python"

print(text[0:6:2])
Pto

Index 0 → P, 2 → t, 4 → o.

2. Every Second Character

text = "ABCDEFGH"

print(text[::2])
ACEG

3. Every Third Character

print(text[::3])
ADG

4. Reverse String

text = "Python"

print(text[::-1])
nohtyP
Remember: [::-1] Python me string/list ko reverse karne ka very common shortcut hai.

5. Last 3 Characters

filename = "server.log"

print(filename[-3:])
log

6. First 4 Characters

server = "web-server"

print(server[:4])
web-

7. Remove First Character

text = "Python"

print(text[1:])
ython

8. Remove Last Character

text = "Python"

print(text[:-1])
Pytho

9. Useful DevOps Example — File Extension

filename = "backup.tar.gz"

print(filename[-2:])

Note: real file extensions ke liye slicing ke saath-saath split() ya pathlib jaise safer approaches bhi use kiye ja sakte hain.

9. Methods in String

String methods built-in operations hain jo string ke saath common tasks perform karne me help karte hain.

Examples:

strip() split() join() startswith() endswith() find() upper() lower() replace()

Method ka Basic Syntax

string.method()

Example:

name = "pavan"

print(name.upper())
PAVAN
Important: Python strings immutable hoti hain. String method generally original string ko modify nahi karta; instead ek new string return karta hai.

10. strip()

strip() string ke beginning aur end ke unwanted whitespace ko remove karta hai. 

name = "   Pavan   "

print(name.strip())
Pavan

lstrip()

Left side ka whitespace remove karta hai.

text = "   Python"
print(text.lstrip())
Python

rstrip()

Right side ka whitespace remove karta hai.

text = "Python   "
print(text.rstrip())
Python

Why Useful in DevOps?

server = input("Enter server: ").strip()

print(f"Connecting to {server}")

User input ya command output me extra spaces ho sakte hain; strip() clean data ke liye useful hai.

Note: strip() string ke beech ke spaces remove nahi karta.

11. split()

split() string ko parts me divide karke list return karta hai. 

text = "Python for DevOps"

words = text.split()

print(words)
['Python', 'for', 'DevOps']

Default me whitespace ke basis par split hota hai.

Comma ke basis par Split

servers = "web,db,cache"

print(servers.split(","))
['web', 'db', 'cache']

Specific Separator

data = "pavan@example.com"

print(data.split("@"))
['pavan', 'example.com']

Limit ke saath

text = "one-two-three-four"

print(text.split("-", 2))
['one', 'two', 'three-four']
DevOps Use: Logs, command output, CSV-like values, environment variables aur configuration strings ko parse karne me split() bahut useful hai.

12. join()

join() ka use multiple strings ko ek single string me combine karne ke liye hota hai.

Important: split() string → list karta hai, jabki join() list/iterable → string karta hai. 
words = ["Python", "for", "DevOps"]

sentence = " ".join(words)

print(sentence)
Python for DevOps

Comma Separator

servers = ["web", "db", "cache"]

result = ", ".join(servers)

print(result)
web, db, cache

Hyphen Separator

parts = ["2026", "10", "01"]

date = "-".join(parts)

print(date)
2026-10-01

Split + Join Together

text = "Python    for    DevOps"

words = text.split()
clean_text = " ".join(words)

print(clean_text)
Python for DevOps

Ye technique extra whitespace ko normalize karne ke liye useful hai.

13. startswith()

startswith() check karta hai ki string kisi particular text se start hoti hai ya nahi. Result True ya False hota hai. 

filename = "backup.tar.gz"

print(filename.startswith("backup"))
print(filename.startswith("server"))
True False

Practical Example

log = "ERROR: Disk full"

if log.startswith("ERROR"):
    print("Error log detected")

Multiple Possible Prefixes

filename = "backup-2026.tar"

print(filename.startswith(("backup", "archive")))
True
DevOps Use: Logs ko classify karna, file naming patterns check karna, command output ke prefixes identify karna.

14. endswith()

endswith() check karta hai ki string kisi particular text se end hoti hai ya nahi. 

filename = "server.log"

print(filename.endswith(".log"))
print(filename.endswith(".txt"))
True False

File Type Check

filename = "config.yaml"

if filename.endswith(".yaml"):
    print("YAML configuration file")

Multiple Extensions

filename = "config.yml"

print(filename.endswith((".yaml", ".yml")))
True
DevOps Use: Logs, configuration files, scripts aur generated artifacts ke extensions check karne me useful.

15. find()

find() string ke andar kisi substring ka first matching index return karta hai. 

text = "Python for DevOps"

print(text.find("DevOps"))
11

"DevOps" ka first character D index 11 par hai.

Substring Not Found

text = "Python"

print(text.find("Java"))
-1
Important: find() substring nahi milne par -1 return karta hai.

Start Position ke baad Search

text = "Python Python"

print(text.find("Python", 1))

Search index 1 se start hoga, isliye second occurrence mil sakta hai.

Practical Log Example

log = "INFO: Server started successfully"

position = log.find("Server")

if position != -1:
    print("Server keyword found")
    print("Position:", position)

16. in Operator

in operator check karta hai ki koi character ya substring string ke andar present hai ya nahi. 

text = "Python for DevOps"

print("Python" in text)
print("DevOps" in text)
print("Java" in text)
True True False

if ke saath

log = "ERROR: Connection failed"

if "ERROR" in log:
    print("Error detected!")

not in

text = "Python"

if "Java" not in text:
    print("Java is not present")
Java is not present

find() vs in

Method Result Use
in True / False Sirf presence check karni ho
find() Index / -1 Substring ki position chahiye 
text = "Python"

print("tho" in text)       # True
print(text.find("tho"))    # 2

17. Strings in DevOps — Practical Examples

Example 1 — Log Detection

log = "ERROR: Database connection failed"

if "ERROR" in log:
    print("Alert: Error found in logs")

Example 2 — Log Cleanup

log = "   ERROR: Disk full   "

clean_log = log.strip()

print(clean_log)

Example 3 — File Extension Check

filename = "deployment.yaml"

if filename.endswith((".yaml", ".yml")):
    print("Kubernetes configuration file")

Example 4 — Parse Server List

servers = "web01,web02,db01"

server_list = servers.split(",")

print(server_list)

Example 5 — Create Command from List

parts = ["docker", "ps", "-a"]

command = " ".join(parts)

print(command)

Example 6 — Normalize User Input

environment = input("Enter environment: ").strip().lower()

if environment == "production":
    print("Production environment selected")
else:
    print(f"Selected environment: {environment}")
DevOps Connection: Real automation scripts me strings ka use bahut common hai: logs parse karna, commands build karna, filenames check karna, environment variables process karna, API responses handle karna aur configuration data clean karna.
