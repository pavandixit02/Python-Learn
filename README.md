## 🚀 DevOps Automation Example

Python can be used to automate system-related tasks.

```python
import shutil

total, used, free = shutil.disk_usage("/")

print(f"Total Disk: {total}")
print(f"Used Disk: {used}")
print(f"Free Disk: {free}")
```
