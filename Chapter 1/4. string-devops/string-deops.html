1. What are these practicals about?

Your file practices how to clean and standardize text, replace part of a hostname, split server inventories, search logs for keywords, check log prefixes/suffixes, and chain methods together.

String-processing workflow:
Raw text → clean → standardize case → split/search/check → use result.

DevOps scripts frequently process server names, status values, filenames, command output, and log messages. These examples are a foundation for that work.

2. Clean String with strip()

strip() removes whitespace from the beginning and end of a string. It does not remove spaces in the middle.

server = "   devops-server   "
print(server)
print(server.strip())
devops-server devops-server

The first print shows the original spaces. The second prints a cleaned result.

Practical use: clean user input

server = input("Enter server name: ").strip()
print(f"Selected server: {server}")
Important: Strings are immutable. strip() returns a new string; save it with server = server.strip() if you need the cleaned value later.

3. lower() and upper()

lower() converts letters to lowercase; upper() converts letters to uppercase.

lower()

status = input("Enter the status: ").strip().lower()
print(status)

If input is Active , output is:

active

upper()

status = input("Enter the status: ").strip().upper()
print(status)

If input is active , output is:

ACTIVE

Why useful?

A user may type ACTIVE, active, or Active . Normalizing the case makes comparisons consistent.

status = input("Service status: ").strip().lower()
if status == "active":
    print("Service is active")
else:
    print("Service is not active")
Case-sensitive comparison: "ERROR" == "error" is False. Convert both values to the same case before comparing.

4. replace()

replace(old, new) returns a new string where matching occurrences of old are replaced by new.

hostname = "devops-server"
new_hostname = hostname.replace("devops", "prod")
print(new_hostname)
prod-server

Replace all matching occurrences

text = "devops-devops-server"
print(text.replace("devops", "prod"))
prod-prod-server

Limit replacements

print(text.replace("devops", "prod", 1))
prod-devops-server
Safety note: This only changes text in Python. It does not rename a real production host or change infrastructure.

5. split() with different separators

split() divides a string into pieces and returns a list. The separator must match the delimiter in the input.

Comma

server_data = "web01,web02,web03,db01,db02"
print(server_data.split(","))
['web01', 'web02', 'web03', 'db01', 'db02']

Semicolon

"web01;web02;db01".split(";")
['web01', 'web02', 'db01']

Pipe

"web01|web02|db01".split("|")
['web01', 'web02', 'db01']

Whitespace

server_data = "web01 web02 web03 db01 db02"
print(server_data.split())
['web01', 'web02', 'web03', 'db01', 'db02']

Without an argument, split() separates on whitespace and handles repeated spaces.

Colon

"web01:web02:db01".split(":")
['web01', 'web02', 'db01']

Use the returned list

servers = "web01,web02,db01".split(",")
print(servers[0])
print(servers[2])
print(len(servers))
web01 db01 3
DevOps use: Parse simple server inventories or delimiter-separated text into a list. For complex CSV files, use Python's csv module instead.

6. in operator

in checks whether a substring exists in a string. The result is True or False.

log = "ERROR nginx service failed"
print("ERROR" in log)
print("WARNING" in log)
True False

Log detection

log = "ERROR nginx service failed"
if "ERROR" in log:
    print("Alert: error found in log")
Alert: error found in log

To make the keyword check case-insensitive, normalize the log:

if "error" in log.lower():
    print("Error keyword found")

7. startswith() and endswith()

startswith() checks the beginning of a string. endswith() checks the ending. Both return Boolean values.

log = "ERROR nginx service failed"
print(log.startswith("ERROR"))
print(log.endswith("failed"))
True True

Classify a log

if log.startswith("ERROR"):
    print("This is an error log")
if log.endswith("failed"):
    print("Message ends with failure")
This is an error log Message ends with failure

Filename check

filename = "backup.log"
print(filename.endswith(".log"))
print(filename.startswith("backup"))
True True
DevOps use: Check log prefixes, file extensions, and naming conventions.

8. Chaining string methods

Method chaining means calling another method on the value returned by the previous method.

status1 = "   RUNNING   "
status1 = status1.strip().lower()
print(status1)
running

Step-by-step:

  1. strip() returns "RUNNING".
  2. lower() runs on that result and returns "running".
  3. The final value is assigned back to status1.

Direct chaining with input

status2 = input("Enter the status: ").strip().upper()
print(status2)

Input active produces:

ACTIVE

Another example

server = "   WEB01   "
server = server.strip().lower()
print(server.startswith("web"))
True

9. Combined DevOps practical: text analyzer

This practice combines the same methods from your file. It cleans a status, splits a server list, checks a log, and demonstrates a hostname text replacement.

status = input("Enter service status: ").strip().lower()
print(f"Normalized status: {status}")

server_data = input("Enter servers separated by commas: ").strip()
servers = server_data.split(",")
print(f"Server list: {servers}")
print(f"Number of servers: {len(servers)}")

log = input("Enter a log message: ").strip()
if "error" in log.lower():
    print("Alert: error keyword found")
if log.upper().startswith("ERROR"):
    print("Log starts with ERROR")
if log.lower().endswith("failed"):
    print("Log ends with failed")

hostname = input("Enter hostname: ").strip()
print("Updated text preview:", hostname.replace("devops", "prod"))
The hostname replacement is only a text preview. It does not change the actual host configuration.

10. Common mistakes

MistakeCorrection / explanation
Calling status.strip() without saving itUse status = status.strip() if you need the cleaned result.
Searching lowercase text in uppercase logsUse "error" in log.lower().
Using the wrong separator for split()The delimiter must match the data.
Assuming replace() changes the original variableSave or print the returned string.
Using startswith() to search anywhereUse in for presence anywhere.
Using endswith() to check the prefixUse startswith() for the beginning.
