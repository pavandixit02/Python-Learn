1. Type Conversion

Type conversion ka matlab ek data type ki value ko doosre data type me convert karna hai.

Most important DevOps pattern:
input() → string → conversion → number → comparison → True/False

Python ka input() normally user input ko str ke form me return karta hai. Agar hume us value par mathematical operation ya numeric comparison karna hai, to usse int() ya float() me convert karna padta hai.

FunctionConversionExampleTypical Use
int()String/number → integerint("25")Age, count, port, CPU percentage
float()String/number → decimalfloat("25.5")Temperature, percentage, measurements
str()Value → stringstr(25)Messages, filenames, text output
bool()Value → Booleanbool(1)True/False logic

2. int() — Convert to Integer

int() ka use compatible value ko whole number/integer me convert karne ke liye hota hai.

age = input("Enter your age: ")
age = int(age)
print(age + 5)

Flow: input() value leta hai → value string hoti hai → int() integer banata hai → ab mathematical operation possible hai.

Shortcut

age = int(input("Enter your age: "))
print(age + 7)
Important: int("25") valid hai, lekin int("hello") ValueError dega.

DevOps Example

cpu_usage = int(input("Enter CPU Usage: "))

if cpu_usage > 90:
    print("Critical CPU usage")

3. float() — Convert to Decimal

float() kisi value ko decimal/floating-point number me convert karta hai.

temp = input("Enter your temperature: ")
temp = float(temp)
print(temp)

Shortcut

temp = float(input("Enter your temperature: "))
print(temp)

Example

usage = float("75.5")
print(usage)
print(type(usage))
75.5 <class 'float'>
Use: decimal values jaise temperature, percentage ya measurements ke liye.

4. str() — Convert to String

str() kisi value ko text/string me convert karta hai.

age1 = 25
age1_text = str(age1)
print(type(age1_text))
<class 'str'>

Practical Example

port = 8080
print("Application port: " + str(port))

Modern Python me f-string aur cleaner hota hai:

port = 8080
print(f"Application port: {port}")
Common mistake: "Port: " + 8080 direct concatenate nahi kar sakte, kyunki types different hain.

8. Comparison Operators

Comparison operators do values ko compare karte hain aur result True ya False hota hai.

OperatorMeaningExample
==Equal10 == 10 → True
!=Not Equal10 != 5 → True
>Greater Than10 > 5 → True
<Less Than10 < 5 → False
>=Greater or Equal10 >= 10 → True
<=Less or Equal10 <= 5 → False

DevOps Example

cpu_usage = 95
print(cpu_usage > 90)
True
Common mistake: = assignment ke liye aur == comparison ke liye hota hai.

9. Logical Operators

and

and tab True deta hai jab dono conditions True hon.

cpu = 70
memory = 60
print(cpu < 80 and memory < 80)
True

or

or tab True deta hai jab kam se kam ek condition True ho.

cpu = 95
memory = 50
print(cpu > 90 or memory > 90)
True

not

not Boolean result ko reverse karta hai.

status = True
print(not status)
False
DevOps: and multiple health conditions, or alert conditions aur not opposite status check ke liye useful hai.

10. Assignment Operators

Assignment operators variable ko assign aur update karne ke liye use hote hain.

Normal Use

count = 10
count = count + 1
print(count)
11

Shortcut Use

count = 10
count += 1
print(count)
11
OperatorEquivalentMeaning
+=x = x + yAdd and assign
-=x = x - ySubtract and assign
*=x = x * yMultiply and assign
/=x = x / yDivide and assign
%=x = x % yRemainder and assign
**=x = x ** yPower and assign
//=x = x // yFloor divide and assign

Shortcut ka benefit: code concise aur readable hota hai.

11. DevOps Practical Example

Tumhari practical file me server name, CPU usage aur memory usage li jaati hai. CPU aur memory ko int() se number me convert karke > 90 threshold se compare kiya jata hai.

server_name = input("Enter Server Name : ")
cpu_usage = int(input("Enter CPU Usage : "))
memory_usage = int(input("Enter Memory Usage : "))

print("=======SERVER MATRICS=======")
print(f"Server Name     : {server_name}")
print(f"CPU Usage       : {cpu_usage}%")
print(f"Memory Usage    : {memory_usage}%")

print(f"CPU Critical    : {cpu_usage > 90}")
print(f"Memory Critical : {memory_usage > 90}")
print("============================")

Step-by-Step

StepConceptExplanation
1input()User data leta hai; input string hota hai.
2int()CPU/memory text ko integer banata hai.
3VariablesValues ko store karta hai.
4Comparison> 90 threshold check karta hai.
5BooleanTrue/False result deta hai.
6f-stringReadable status report banata hai.

Example Run

Enter Server Name : web-server-01
Enter CPU Usage : 95
Enter Memory Usage : 70
=======SERVER MATRICS======= Server Name : web-server-01 CPU Usage : 95% Memory Usage : 70% CPU Critical : True Memory Critical : False ============================
Foundation of DevOps Automation:
input() → string → int() → number → compare → TRUE/FALSE

🔥 Mini Project — Server Health Checker

server_name = input("Enter Server Name: ")
cpu_usage = int(input("Enter CPU Usage: "))
memory_usage = int(input("Enter Memory Usage: "))

cpu_critical = cpu_usage > 90
memory_critical = memory_usage > 90

print("\n======= SERVER HEALTH =======")
print(f"Server Name     : {server_name}")
print(f"CPU Usage       : {cpu_usage}%")
print(f"Memory Usage    : {memory_usage}%")
print(f"CPU Critical    : {cpu_critical}")
print(f"Memory Critical : {memory_critical}")

if cpu_critical or memory_critical:
    print("Status          : ALERT")
else:
    print("Status          : NORMAL")

print("=============================")
